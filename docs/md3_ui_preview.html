新增的 3 个排版与手势功能

  • 1. 行距调节 采用 M3 SegmentedButton 四档快选（1.2x / 1.4x / 1.6x / 1.8x），远距离大字不再挤成一团。
  • 2. 正文字重 支持「常规体 / 加粗」一键切换，强灯光下或架在相机兔笼远看时，未读白色字笔画更醒目。
  • 3. 快捷 + 捏合 底部悬浮条内置紧凑 A- / A+，同时台词区支持双指捏合实时缩放，缩放时顶部弹出字号提示胶囊（自动记忆横/竖屏）。

参考 MD3 / M3 Expressive 升级点

  • • 色调层级 (Tonal Elevation)：台词底色保持 OLED 纯黑 #000000（防镜头反光），编辑页与抽屉改用 MD3 SurfaceContainer 阶梯深灰，层次更干净。
  • • Expressive 拆分底栏：左侧全圆角 FloatingToolbar 放低频辅助键，右侧独立主操作 Morphing FAB（暂停为 16dp 圆角矩形、播放态变形为胶囊/正圆）。
  • • 28dp 抽屉 + 分组卡片：设置面板采用外大圆角（20dp）、组内小圆角（6dp）卡片分隔排版/模式/开关，视觉扫视负担大幅下降。
  • • 动态配色兼容：支持在设置或随系统切换莫奈动态取色 / 专业高对比琥珀金。
